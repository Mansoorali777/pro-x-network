Anti-Cheat

What's actually enforceable from a static app, and the controls you have.
State tampering (always on): every player's saved progress carries an integrity signature. If someone edits their balance directly in browser storage, the app detects the mismatch on next load and resets their progress — logged below as a "CHEAT FLAG". This deters casual editing but not a determined attacker running their own client; only a server-authoritative backend closes that gap completely.
Why there's no "1 account per network" control: a webpage cannot see other devices on the same WiFi or mobile network — there's no browser API for it. Enforcing it server-side via IP address was considered and left out on purpose: mobile carriers put thousands of unrelated phones behind one shared IP (carrier-grade NAT), and every device on a home or office WiFi shares one IP too. IP-based blocking would lock out real, unrelated users far more often than it would catch cheaters.
The real fix for multi-accounting: since this is a Telegram Mini App, each player already carries their real, phone-verified Telegram account ID — the app now uses that as their identity instead of a random code. That's a much stronger "one real person, one account" signal than network or device ever could be, and it works automatically with no extra config.
